# SentinelVision
AI-powered real-time human and drone detection &amp; tracking system using YOLO and OpenCV.
SentinelVision is an AI-powered surveillance and tracking system capable of detecting and tracking both humans and drones in real-time using YOLOv8 and OpenCV.

Features:
- Real-time Human Detection
- Real-time Drone Detection
- Separate Tracking Windows
- Multi-Target Tracking
- YOLOv8 Integration
- OpenCV Visualization
- Lightweight & Fast
